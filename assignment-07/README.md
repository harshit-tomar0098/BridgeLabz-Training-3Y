# Assignment-07

This folder contains solutions for all 9 JavaScript DOM assignments.

## Files
Each question has its own HTML, CSS, and JavaScript file:
- Q1: Dynamic Product List Manager (event delegation and inline editing)
- Q2: Live Character Counter
- Q3: Multi-Step Form with validation
- Q4: Theme Switcher using setAttribute()
- Q5: Image Gallery with Modal Preview
- Q6: Real-Time Student Table Filter
- Q7: Mouse Coordinates and Double-Click Dots
- Q8: Custom Dropdown using capturing phase
- Q9: Form Submit Blocker with live validation

## Run
Open the required HTML file in a browser. Each HTML file loads its matching CSS and JavaScript file.
The examples use core JavaScript only. The image gallery loads sample images from picsum.photos and needs an internet connection for those images.
