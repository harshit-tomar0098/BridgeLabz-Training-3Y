# H JS Assignment 1

Solutions for Questions 1–10 using core JavaScript only.

## How to run
- Install Node.js, then open a terminal in this folder.
- Run one question at a time, for example: `node q1_personalized_login_greeting.js`
- Each question is in a separate `.js` file.
- Inputs are represented by editable test variables so each script runs directly in Node.js without extra libraries.

- `q2_multi_type_data_summary.js`
