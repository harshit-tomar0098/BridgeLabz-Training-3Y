# JavaScript Assignment 2

This folder contains solutions to Q1–Q10. Each question is in a separate JavaScript file.

## Run a solution

With Node.js installed, open a terminal in this folder and run, for example:

```bash
node Q1_scope_conflict_resolver.js
```

Replace the filename with any other `Q*.js` file to run that question. Q4 generates new random scores each run, and Q3 generates a random number between 10 and 50.

## Files

1. `Q1_scope_conflict_resolver.js` — global and local scope
2. `Q2_string_manipulation_report.js` — string methods and title formatting
3. `Q3_math_utility_dashboard.js` — Math methods and template literals
4. `Q4_array_performance_analyzer.js` — random scores and array methods
5. `Q5_boolean_logic_access_system.js` — Boolean conditions and test cases
6. `Q6_event_based_counter_simulation.js` — counter functions and nested scope
7. `Q7_customer_feedback_processor.js` — feedback analysis
8. `Q8_dynamic_discount_evaluator.js` — category and cart discounts
9. `Q9_odd_even_number_analyzer.js` — FizzBuzz/even/odd classification
10. `Q10_departmental_employee_evaluator.js` — department score evaluation
