# JavaScript Assignment 3

Solutions for Q1–Q10, each in its own JavaScript file. Examples use strict mode where relevant and include comments for debugger exercises.

## Run a question

With Node.js installed, open a terminal in this folder and run:

```bash
node Q1_dynamic_data_parser.js
```

Replace the filename to run another question.

## Debugging in VS Code

1. Open this folder in VS Code.
2. Open the desired `.js` file.
3. Click to the left of a line number to add a breakpoint (or use the included `debugger;` statements).
4. Open **Run and Debug** and start the Node.js debugger.
5. Inspect Variables / Watch and the Call Stack panel.
