# Assignment 6 – Async JavaScript

Folder name: `assignment-async`

## Files
- `Q1.js` – Promise chaining and error handling
- `Q2.js` – Event loop: microtasks and macrotasks
- `Q3.js` – Callback-to-Promise conversion
- `Q4.js` – `Promise.all()` and `Promise.race()`
- `Q5.js` – Callback hell and async/await
- `Q6.js` – Fetch product data from Fake Store API
- `Q7.js` – `Promise.allSettled()` and execution time
- `Q8.js` – Retry mechanism with async/await
- `Q9.js` – Event loop execution order
- `Q10.js` – Asynchronous delivery pipeline

## How to run
Open a terminal in this folder and run an individual question:

```bash
node Q1.js
```

Replace `Q1.js` with `Q2.js`, `Q3.js`, and so on.

Use Node.js 18 or newer for Q6 because it uses the built-in `fetch()` function.
Some questions intentionally use random failures, so running them again may produce a different result.
